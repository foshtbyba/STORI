# ПРОМТ: перенос лендинга и сундука на новую партнёрку

Скопируй весь этот промт, заполни блок «ПЕРЕМЕННЫЕ», приложи файлы — и отправь мне.
Я выполню все шаги: почищу от старой партнёрки, вставлю передачу заказов/статистики,
привязку конверсий, демонетизацию (BackFix), ребрендинг — и пришлю готовый архив.

---

## ЧТО ПРИЛОЖИТЬ ВМЕСТЕ С ПРОМТОМ
- `index.html` старого лендинга
- `chest.html` (сундук), если есть
- если новая партнёрка НЕ M1 — её гайд по API (передача заказов + статистика)
- картинки нового оффера (или скажи, что зальёшь сам, я только пропишу имена)
- при необходимости: `js/m1ref.js`, `js/ywbackfix.js` (если поменялись)

## ПЕРЕМЕННЫЕ (заполни перед отправкой)
- OFFER_NAME_OLD = (старое имя товара в коде, напр. DHT19)
- OFFER_NAME_NEW = (новое имя, напр. Alpha Beast)
- PRODUCT_ID = (ID товара в партнёрке)
- WEBMASTER_ID = (твой ID в партнёрке)
- WEBMASTER_API = (API-ключ)
- GEO_LANGCODE = (напр. it / es / de)
- PRICE_OLD = (зачёркнутая цена)
- PRICE_NEW = (актуальная цена)
- CURRENCY = (напр. EUR)
- IMG_MAIN = (имя основной картинки товара, напр. AlphaBeast.png)
- IMG_FORM = (имя картинки для формы/сундука, напр. AlphaBeast-2.png)
- FAVICON = (напр. favicon.ico)
- THANKYOU_PAGE = call.html        (по умолчанию)
- ERROR_PAGE = error.html          (по умолчанию)
- DEMONET / BackFix (для лендинга):
  - TRACKER_DOMAIN = (домен трекера, напр. nutrivition.top)
  - CHEST_CAMPAIGN = (токен Keitaro-кампании сундука, напр. VXsVxCX)
  - ROUTING_PARAM = (имя параметра разделения потоков, напр. sun)
  - ROUTING_VALUE = (значение; напр. макрос {sub_id_30} или статичное)
- KEITARO_SUBID = {subid}          (макрос трекера для привязки конверсий)
- REVIEW_PHOTOS = (опц.: файлы фото-отзывов + в какие комментарии вставить)
- REMOVE_COMMENTS = (true/false — убрать ли все комментарии в коде)

## ЗАДАЧИ — ВЫПОЛНИ ПО ШАГАМ

### A. Чистка от старой партнёрки (и лендинг, и сундук)
1. Форму заказа: `action="/order.php"` (или иной endpoint) → `action=""`.
2. Удалить скрытые поля старого трекера/партнёрки: `fbpx/{fbpx}`, `utm_code/{subid}`,
   `cid/{campaign_id}`, `sid`, `hash/{hash}`, `country` и подобные.
3. Удалить старые токены/пиксели/счётчики прошлых партнёров
   (напр. `<p>{_box:...}</p>`, посторонние `<script>` трекеров).
4. НЕ трогать дизайн/контент/квиз и анимацию сундука (`bounce.js`, стили, картинки сундука).

### B. Передача заказов и статистики новой партнёрке
(по умолчанию — M1/m1.top, Method B; для другой партнёрки — по приложенному гайду)
1. Подключить `js/m1ref.js` (статистика) + beacon `send_order/?...&out=1`
   с PRODUCT_ID и WEBMASTER_ID.
2. Вставить AJAX-передачу заказа: на сабмит формы → POST на endpoint партнёра
   (ref, api_key, product_id, name, phone, ip, langCode=GEO_LANGCODE, s/w/t/p/m, referer);
   success → THANKYOU_PAGE, ошибка/дубликат → ERROR_PAGE.
3. В форму добавить служебные поля: `product_id`, `ref`, `langCode`.
4. jQuery использовать уже подключённый в `<head>`; второй НЕ добавлять.
5. Создать THANKYOU_PAGE и ERROR_PAGE, если их нет: на языке GEO, контент по центру,
   картинка товара IMG_MAIN, favicon. На ERROR_PAGE метрики НЕ ставить.

### C. Привязка конверсий к трекеру (Keitaro)
1. В коде заказа захватить click id трекера:
   `var k_sub = '{subid}'; if (k_sub.indexOf('{') !== -1) k_sub = '';`
   и передавать его в параметр `s` партнёру (`client_s = QueryString.s || k_sub`).
2. Напомнить мне (юзеру) настроить постбэк «партнёрка → Keitaro» по параметру `s`.

### D. Демонетизация (BackFix) — ТОЛЬКО на лендинге
1. Положить `js/ywbackfix.js`.
2. Перед `</body>` вставить:
   ```
   <script src="js/ywbackfix.js"
     data-redirect="true"
     data-links='["https://TRACKER_DOMAIN/CHEST_CAMPAIGN?ROUTING_PARAM=ROUTING_VALUE"]'>
   </script>
   ```
3. На проде — без `data-traceenabled`. Помнить: `data-links` — JSON
   (массив в одинарных кавычках, ссылки в двойных).

### E. Ребрендинг под новый оффер (и лендинг, и сундук)
1. Заменить OFFER_NAME_OLD → OFFER_NAME_NEW во всех файлах.
2. Картинки товара: основная → IMG_MAIN, в форме/сундуке → IMG_FORM.
   Проверить размер/центрирование (увеличить, если мелкая; центрировать через
   display:block;margin:auto или flex).
3. Favicon → FAVICON (`<link rel="icon" ...>`), правильный type.
4. Цены: зачёркнутая = PRICE_OLD, актуальная = PRICE_NEW, валюта = CURRENCY.
5. (опц.) Вставить REVIEW_PHOTOS в указанные комментарии (адаптивно, по центру).

### F. Сундук (chest.html) — повторить A + B + C + E, но:
- BackFix (D) в сундук НЕ ставить (это страница назначения демонетки).
- Имя/цена/картинка IMG_FORM; форма → AJAX партнёрки → THANKYOU/ERROR.

### G. Финал
1. Если REMOVE_COMMENTS=true — убрать все комментарии-пояснения и дебаг.
2. Проверить: не осталось OFFER_NAME_OLD, старых endpoint/макросов, плейсхолдеров,
   `data-traceenabled`, временных костылей.
3. Собрать архив (index.html, chest.html, call.html, error.html, js/*) и прислать.
4. Дать чек-лист: что залить на хостинг и что настроить в кабинете партнёрки и в Keitaro.
