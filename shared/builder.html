Конструктор лендов

берёт переведённый ленд (HTML или папку), подключает форму к партнёрке, ставит Meta Pixel и делает call/error/chest → готовая сборка

Партнёрка

На карточке оффера в дешборде — кнопка «Копировать для билдера». Вставь строку сюда: партнёрка, ID, гео и остальное встанут сами.
⚠ Обязательно. Возьми точный URL лендинга со страницы оффера в shakes. Без него (или с чужим URL) партнёрка не примет лид — заявка не улетит.
▸ Расширенные (код потока)
shakes: форма постит на серверный order.php (генерируется автоматически с твоим ключом, ID оффера, landingUrl и страницами call/error). ref не нужен, страна — авто из «Код гео», streamCode — только для статистики. Хост должен поддерживать PHP. Загружай ленд папкой.
SkyLead: форма постит на серверный order.php (генерируется с закреплённым ключом, offer и flow), лид уходит на api.skylead.biz/wm/push.json. ID оффера (offer) — в поле выше, API-ключ закреплён за партнёркой. Страна — авто из «Код гео». Хост с PHP+cURL.
⚠ lemon.php у каждого оффера свой (внутри его OFFER_ID и токен). Загружай новый под каждый оффер. Файл кладётся в сборку без изменений. success.php/error.php генерятся сами.
⚠ Папка api у KMA своя под оффер (внутри config.php с токеном/каналом). Кладётся в ленд как api/, а api/success.php заменяется на наш дизайн (переведённый + пиксель).
🔒 ref и api_key закреплены за выбранной партнёркой и подставляются автоматически — руками не меняются. Для новой партнёрки выбери «Другая (вручную)» или добавь адаптер.

▸ Сундук (chest.html)

Отдельная страница-рулетка «крутите — выиграли скидку». Нужна не всегда. Если включено — появится кнопка «⬇ Сундук», текст переводится на язык ленда, фото берётся то же, что на call/error. Без своей папки — генерируется по образцу.

▸ Meta Pixel (конверсии FB)

▸ Расширенные (ценность/валюта — нужны для Purchase/ROAS)
PageView — на index/chest/error. Событие конверсии — на success (call.html), после подтверждённого заказа. Для обычного COD-лида (Lead) ценность/валюта не нужны — оставь пустыми.

Страницы и ссылки

Куда ленд ведёт после отправки формы и на каком языке будут служебные страницы.
success — страница «спасибо» при успешном заказе (там срабатывает конверсия). error — при сбое отправки. Обычно оставляй как есть.
▸ back-fix ссылка (обычно не трогаем)
Куда увести юзера по кнопке «Назад» (демонетизация трафика). Пусто — выключить. Домен/путь берём из Keitaro: в кампании задай sub_id_29 = домен (напр. nutrivition.top), sub_id_30 = путь без слэша (напр. VXsVxCX) — только буквы/цифры, БЕЗ / : ? (иначе Keitaro закодирует). {campaign_alias} = идентификатор кампании — подставляется сам. Протокол, слэши и ?sun= держим в коде.
Если заполнено — в ленд встанет <script src="этот URL">, а локальный js/ywbackfix.js в архив НЕ кладётся (обновляешь скрипт в одном месте на сервере). Пусто — как раньше, скрипт кладётся в архив.
▸ Метка баера (для партнёрок)
Код баера летит в партнёрку в её саб-поле. В Keitaro один раз на поток: Параметры → sub_id_2 → имя buyer, значение = код баера (напр. SKO). Билдер сам кладёт {sub_id_2} в нужное поле: shakes→sub2, SkyLead→utm_content, everad/rocketprofit→sid2. (m1/KMA — добавлю по гайду.)
На каком языке генерятся служебные страницы (спасибо/ошибка/сундук). На перевод самого ленда не влияет.

▸ Оптимизация (вес / скорость)

Уменьшает вес и ускоряет ленд. Base64 выносится в файлы, картинки жмутся под реальный размер, лишние/чужие файлы удаляются. После скачивания здесь появится отчёт: что сделано и сколько сэкономлено.

Источник

Если форма на ленде без нужной разметки — сам проставит data-order-form и name/phone, чтобы заказ ловился. Оставляй включённым.
Удаляет старые скрипты отправки любой известной партнёрки (m1.top/sendData, shakes order.php-обработчик, countries.js…) и старый Meta Pixel, чтобы не было дублей с нашим блоком. Оставляй включённым. Сними, только если хочешь сохранить чужой обработчик формы (напр. countries.js для «умной» формы shakes).
Перегенерит эти страницы под наш шаблон и выбранный язык. Сними, если у тебя свои call/error, которые нужно сохранить.
По умолчанию выключено: готовый ленд чистый, без служебных <!-- … --> конструктора. Включи, если хочешь видеть пометки, что и куда вставлено.
▸ 🌐 Перевод ленда через Claude
Ключ запоминается только в этом браузере (localStorage) — в файл/репозиторий не попадает, отправляется только на api.anthropic.com. Чтобы убрать — очисти поле.
Перевод — задача механическая, поэтому «Быстро/Баланс» обычно достаточно и заметно шустрее. «Качество» — если нужна очень аккуратная локализация. (Для Haiku не применяется.)
