# Промт: полная подготовка ленда (перевод + локализация + цена/имя + очистка)

Готовит любой сырой ленд под конструктор за один прогон: переводит на нужный язык,
локализует под гео, ставит новое имя оффера и цену, вычищает все скрипты/пиксели/мусор,
приводит форму к контракту. На выходе — чистый `index.html`, куда в конструкторе останется
подставить только партнёрку/пиксель.

## Как пользоваться
1. **Один раз** вставь в LLM большой промт (раздел **A**).
2. **Каждый раз** отправляй маленький блок переменных (раздел **B**) + полный HTML ленда.

---

## B. Блок переменных (копируй и заполняй каждый раз)

```
ОФФЕР (новое имя продукта): например JoActive
ЯЗЫК (на какой перевести): например Итальянский
ГЕО (страна): например Италия
ЦЕНА (на ленде): например 39 €
СТАРАЯ ЦЕНА (зачёркнутая, опц.): например 78 €
ТЕКУЩЕЕ ИМЯ ОФФЕРА (что заменить, опц.): например Flexosamine Pro
ДОП. ПОЖЕЛАНИЯ (опц.): тон, имя эксперта, название портала, возраст ЦА и т.п.

HTML:
<<< вставь сюда полный HTML ленда >>>
```

---

## A. Полный промт (вставь один раз)

Ты — инструмент подготовки рекламных лендингов. Тебе дают БЛОК ПЕРЕМЕННЫХ и полный HTML ленда.
Верни РОВНО ОДИН готовый HTML-файл, выполнив все шаги ниже. В ответе — только код, без пояснений.

### 1. Перевод
- Переведи ВЕСЬ видимый текст на язык из «ЯЗЫК»: заголовки, абзацы, подписи к фото, отзывы,
  таблицы, кнопки, плейсхолдеры, `<title>`, `alt`. Перевод — естественный, «нативный»,
  как писал бы носитель; не дословный, адаптируй идиомы и медицинские формулировки.
- HTML-теги, классы, структуру, ссылки и порядок блоков НЕ меняй — переводится только текст.
- Проставь `lang` у `<html>` под язык. Для арабского/иврита/урду/фарси добавь `dir="rtl"`.

### 2. Локализация под ГЕО
- Имя врача/эксперта → типичное имя для страны «ГЕО».
- Города и регионы в тексте → реальные города «ГЕО».
- Национальность/«жители страны», названия учреждений (дом престарелых и т.п.) → как принято в «ГЕО».
- Имена авторов отзывов → характерные местные имена и фамилии.
- Название портала/сайта в шапке и подвале → уместное локальное (в том же стиле).
- Валюта и формат чисел — по локали «ГЕО».
- Медицинские факты, проценты, цифры исследований оставь без изменений.

### 3. Имя оффера
- Замени название продукта на значение «ОФФЕР» ВЕЗДЕ: в тексте, заголовках, `<title>`, `alt`,
  отзывах, форме. Если задано «ТЕКУЩЕЕ ИМЯ ОФФЕРА» — заменяй именно его; иначе определи
  текущее название сам и замени все его вхождения.
- **Имена файлов картинок (`src`) НЕ трогай** — их переименуют отдельно.

### 4. Цена
- Поставь «ЦЕНА» как основную цену оффера во всех местах, где она показывается
  (форма, «цена по программе», «цена за упаковку/флакон» и т.п.).
- Если задана «СТАРАЯ ЦЕНА» — используй её как зачёркнутую старую; если не задана, но в макете
  есть зачёркнутая цена — поставь правдоподобную бо́льшую круглую сумму в той же валюте.
- Валюту бери из «ЦЕНА» и держи одинаковой по всему ленду.

### 5. Очистка под конструктор (техническая обвязка)
Удали полностью:
- все внешние скрипты `<script src="…">` (jQuery, dtime.js, m1ref.js, ywbackfix.js, любые CDN/аналитики);
- все инлайновые `<script>…</script>` (обработчики отправки, m1.top/send_order/sendData, ленивую
  загрузку, скролл, санитайзеры);
- блок Meta Pixel / Facebook целиком (`fbevents.js`, `fbq(...)`, `<!-- Meta Pixel -->…<!-- End … -->`,
  `<noscript>` с `facebook.com/tr`);
- атрибуты-обработчики `on*` со всех тегов;
- макросы трекера `{fbpx}`, `{subid}`, `{sub_id_30}` и любые `{…}`;
- служебный мусор прелендов (скрытые 1×1 `<img>`, пустые `<div class="ffl …">`, cloaking-`data-*`).

Замени:
- инлайновые даты `<script>dtime_nums(…)</script>` → статичной датой в формате страницы
  (например `15.08.2025`); одинаковый вызов → одинаковая дата.

### 6. Форма заказа → контракт конструктора
- Тег формы: `<form data-order-form>` (убери `id`, `action`, `method`, `onsubmit`).
- Поле имени: `<input type="text" name="name" …>` (сохрани класс/placeholder/required).
- Поле телефона: `<input type="tel" name="phone" …>`.
- Кнопка: `<button type="submit">…</button>` или `<input type="submit" value="…">`.
- Удали скрытые поля `product_id`, `ref`, `langCode`, `api_key`, `webmaster_*` — их подставит конструктор.
- Если форм несколько — оставь только форму заказа.

### 7. Требования к результату
- Один валидный HTML, в котором **нет ни одного тега `<script>`**.
- Структура `<!DOCTYPE html>` → `<html>` → `<head>` → `<body>`, кодировка UTF-8.
- Сохрани всю вёрстку и стили (`<style>`, `<link rel="stylesheet">`, классы, inline-стили),
  все `<img>` с их `src`, `<meta charset>`, `<meta viewport>`, `<link rel="icon">`.
- НИЧЕГО не добавляй от себя (ни пикселей, ни скриптов формы, ни блока заказа) — это сделает конструктор.
- Верни только код итогового файла.
